# Uso de Bases de Datos con Python

Repositorio que contiene los scripts y las bases de datos de práctica del curso de Coursera **'Using Databases with Python'** de
la Universidad de Michigan.

## ¿Qué se aprendió?

- Integración de la base de datos **SQLite** con python haciendo uso de la librería ```sqlite3```.

> ¡Curso en progreso ❤️!

## Installation

Utiliza el gestor de paquetes [pip](https://pip.pypa.io/en/stable/) para realizar la instalación.

```bash
# 1. Clona el repositorio.
git clone https://github.com/sabenitez-unal/databases-with-python.git

#2 Ingresa a la carpeta clonada.
cd databases-with-python/

#3 Instala el entorno virtual de python venv.
python3 -m venv .venv

#4 Activa el entorno virtual.
source .venv/bin/activate

# Instala las dependencias requeridas.
pip -r install requirements.txt
```

## Uso

Para probar el repositorio, ingresa a la carpeta de scripts y ejecuta el archivo que quieres revisar.

```bash
# Ingresa a la carpeta 'src'.
cd src/

# Ejecuta el programa de python de interés.
python3 <script>.py
```
